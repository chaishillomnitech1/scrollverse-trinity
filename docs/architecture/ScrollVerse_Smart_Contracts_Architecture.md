## Overview

The ScrollVerse ecosystem is anchored by 5 foundational smart contracts. These contracts govern the flow of value, the preservation of legacy, the distribution of Zakat, and the sovereign identity of the citizens. All contracts are designed to be immutable, audited, and deployed via Hardhat/Foundry.

## 1. The Sovereign Citizen Identity (ERC-721)
**Contract Name:** `ScrollVerseCitizen.sol`

This contract mints a unique, non-transferable NFT (Soulbound Token) for every user who successfully subscribes via Stripe. It serves as their immutable passport into the ScrollVerse.

**Key Features:**
- **Soulbound:** Cannot be transferred or sold. It is tied to the user's soul/identity.
- **Metadata:** Stores ascendancy level, referral count, and Zakat contribution history.
- **Access Control:** Only the ScrollVerse backend (via Stripe webhook) can mint or update the token.

**Core Function:**
```solidity
function mintCitizen(address to, string memory uri) external onlyBackend {
    require(balanceOf(to) == 0, "One soul, one passport");
    uint256 tokenId = _tokenIdCounter.current();
    _safeMint(to, tokenId);
    _setTokenURI(tokenId, uri);
    _tokenIdCounter.increment();
}
```

## 2. The Zakat Distribution Vault (Smart Contract Wallet)
**Contract Name:** `ZakatVault.sol`

This contract holds the 7.77% of all revenue generated by the ecosystem. It is programmed to automatically distribute funds to verified charitable causes, community grants, and ecosystem development.

**Key Features:**
- **Auto-Distribution:** Can be triggered to distribute funds based on community voting or predefined schedules.
- **Transparency:** Every incoming cent and outgoing grant is permanently recorded on-chain.
- **Multi-Sig Security:** Requires approval from the Flame Council (e.g., 3 of 5 signatures) for large distributions.

**Core Function:**
```solidity
function distributeZakat(address payable recipient, uint256 amount) external onlyCouncil {
    require(address(this).balance >= amount, "Insufficient Zakat funds");
    recipient.transfer(amount);
    emit ZakatDistributed(recipient, amount);
}
```

## 3. The ScrollVerse Native Token (ERC-20)
**Contract Name:** `ScrollCoin.sol` (Symbol: $SCROLL)

The utility and governance token of the ecosystem. Used for micro-transactions, rewarding referrals, and voting on Zakat distributions.

**Key Features:**
- **Deflationary:** A small percentage of every transaction is burned to increase scarcity.
- **Reward Pool:** A dedicated pool for automatically rewarding users who bring in new citizens (Viral Coefficient: 1.18).
- **Governance:** Holding $SCROLL grants voting power in the Flame Council.

**Core Function:**
```solidity
function rewardReferral(address referrer, uint256 amount) external onlyBackend {
    require(balanceOf(rewardPool) >= amount, "Reward pool empty");
    _transfer(rewardPool, referrer, amount);
    emit ReferralRewarded(referrer, amount);

```

## 4. The Eternal Crystal Scroll (ERC-1155)
**Contract Name:** `EternalScroll.sol`

A multi-token contract used to mint digital artifacts, sacred decrees, and historical chat logs. These are the "books" and "manuals" of the ScrollVerse.

**Key Features:**
- **Fractional Ownership:** Allows multiple users to own a piece of a sacred text or artifact.
- **Dynamic Metadata:** The content of the scroll can evolve as the ecosystem grows, but the core truth remains immutable.
- **Monetization:** Creators can earn royalties every time a scroll is traded or accessed.

**Core Function:**

    _mint(account, id, amount, data);
    emit ArtifactMinted(account, id, amount);

## Deployment Strategy

1. **Testnet (Sepolia):** Deploy all 5 contracts to Sepolia for final integration testing with the Stripe webhooks.
2. **Audit:** Submit contracts to a top-tier auditing firm (e.g., CertiK, ConsenSys) for security verification.
3. **Mainnet (Polygon):** Deploy to Polygon for low gas fees and high throughput, ensuring the 50M+ users can interact without friction.
4. **Verification:** Verify all contract source code on Polygonscan for absolute transparency.
